# Política de Privacidade

**Aplicativo:** Diário do Professor Offline  
**Última atualização:** Maio de 2026

O Diário do Professor Offline foi criado para ajudar professores a organizar registros escolares no próprio dispositivo.

## Dados armazenados

O app funciona com abordagem offline-first. Os dados inseridos pelo usuário são salvos localmente no dispositivo, incluindo:

- Turmas.
- Alunos.
- Aulas.
- Presenças.
- Notas.
- Conteúdos e observações.
- Backups.
- Arquivos de exportação.

## Servidores próprios

O app não envia dados escolares para servidor próprio. Não há sincronização obrigatória em nuvem nesta fase.

## Backups e exportações

Backups e exportações são controlados pelo usuário. Quando o professor gera ou compartilha um arquivo, ele escolhe onde salvar ou para quem enviar. Esses arquivos podem conter dados sensíveis de alunos e devem ser protegidos pelo usuário.

## Anúncios

O app usa Google AdMob para exibir anúncios. Os anúncios não recebem as turmas, alunos, notas, presenças ou planilhas criadas no app.

O Google AdMob pode coletar identificadores, dados técnicos do dispositivo e informações de uso conforme as políticas do Google.

## Permissões

O app pode usar permissões relacionadas a arquivos, câmera/fotos ou compartilhamento, conforme os recursos usados pelo professor, como importação, exportação e backup.

## Exclusão de dados

Como os dados são locais, o usuário pode remover informações dentro do app. A desinstalação do aplicativo pode remover os dados locais, salvo arquivos exportados ou backups salvos fora do app.

## Contato

Para dúvidas de privacidade ou suporte, use o canal informado na tela de suporte do app ou consulte [SUPPORT.md](SUPPORT.md).
