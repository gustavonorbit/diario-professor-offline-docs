# Suporte

Use este guia ao relatar problemas do Diário do Professor Offline.

## O que enviar

- Versão do app.
- Modelo do aparelho.
- Versão do Android/iOS.
- Descrição do que aconteceu.
- Passos para reproduzir o problema.
- Prints, se possível.
- Mensagem de erro exibida.
- Se o problema envolve exportação, informe se era XLSX individual ou ZIP em lote.
- Se o problema envolve backup/restauração, informe a origem do arquivo e o momento da falha.

## Antes de operações importantes

Crie um backup antes de:

- Restaurar dados.
- Trocar de aparelho.
- Apagar turmas ou aulas permanentemente.
- Instalar versões novas em ambiente de trabalho real.

## Dados sensíveis

Evite enviar planilhas ou backups com dados reais de alunos em canais públicos. Se for necessário compartilhar um arquivo para suporte, remova ou anonimize informações sensíveis.
